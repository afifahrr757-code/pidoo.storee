# NusaMart — GitHub Pages Marketplace

Website marketplace front-end yang siap di-upload ke GitHub Pages.

## Fitur demo
- Responsive untuk desktop, tablet, dan mobile
- Search produk
- Filter kategori
- Sorting harga/rating
- Product detail modal
- Keranjang belanja demo
- CTA untuk seller
- Toast notification
- Tampilan modern dengan fokus pada konversi

## Cara menjalankan
Buka `index.html` langsung di browser.

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini.
3. Masuk ke **Settings → Pages**.
4. Pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/root`.
6. Simpan. GitHub akan memberi URL website.

## Catatan
Ini adalah front-end/demo. Untuk marketplace sungguhan, tambahkan backend, database, autentikasi, pembayaran, storage gambar, dan sistem order.
